# Metadata Dictionary

| Field | Meaning |
|---|---|
| hazard_id | Stable identifier for a shock or chronic stress |
| service_id | Stable identifier for a critical urban service |
| service_zone_id | Spatial zone where service continuity and vulnerability are assessed |
| service_domain | Water, energy, transport, communications, housing, health, drainage, emergency, public facilities, etc. |
| normal_capacity | Expected service capacity under normal conditions |
| disruption_capacity | Service capacity available during disruption scenario |
| target_recovery_hours | Target time for restoration |
| expected_recovery_hours | Expected restoration time under scenario |
| dependency_weight | Strength of dependency between infrastructure services |
| service_failure_probability | Scenario-level probability or severity proxy for service failure |
| equity_gap_score | Relative gap in service access or recovery for vulnerable populations |
