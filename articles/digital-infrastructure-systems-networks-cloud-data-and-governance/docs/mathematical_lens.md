# Mathematical Lens

## Digital access

\[
A_d =
\frac{N_{\mathrm{users\ with\ affordable\ reliable\ access}}}{N_{\mathrm{users\ needing\ access}}}
\]

Digital access should measure reliable, usable, and affordable access rather than nominal coverage alone.

## Network capacity

\[
C_n =
w_1 B_{\mathrm{bandwidth}} +
w_2 L_{\mathrm{latency}} +
w_3 U_{\mathrm{uptime}} +
w_4 R_{\mathrm{redundancy}}
\]

Network capacity combines bandwidth, latency, uptime, and redundancy.

## Compute and storage capacity

\[
C_c =
w_1 P_{\mathrm{compute}} +
w_2 S_{\mathrm{storage}} +
w_3 G_{\mathrm{geo\ redundancy}} +
w_4 E_{\mathrm{edge\ readiness}}
\]

Compute and storage capacity depends on processing capacity, storage, geographic redundancy, and edge readiness.

## Interoperability

\[
I_o =
\frac{N_{\mathrm{systems\ using\ shared\ standards}}}{N_{\mathrm{systems\ requiring\ exchange}}}
\]

Interoperability measures whether systems that need to coordinate can exchange data through shared standards and governed interfaces.

## Trust and security

\[
T_s =
\alpha S_{\mathrm{security}} +
\beta P_{\mathrm{privacy}} +
\gamma A_{\mathrm{audit}} +
\delta R_{\mathrm{recovery}} +
\theta G_{\mathrm{governance}}
\]

Digital trust depends on security, privacy, auditability, recovery, and governance.

## Digital infrastructure resilience

\[
R_d =
\lambda_1 A_d +
\lambda_2 C_n +
\lambda_3 C_c +
\lambda_4 I_o +
\lambda_5 T_s -
\lambda_6 D_v -
\lambda_7 E_x
\]

Digital infrastructure resilience rises with access, network capacity, compute capacity, interoperability, and trust, while dependency concentration and exposure reduce resilience.
