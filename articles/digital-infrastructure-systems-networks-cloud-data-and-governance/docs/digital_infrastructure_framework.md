# Digital Infrastructure Systems Framework

| Layer | Question | Evidence artifact |
|---|---|---|
| Public-purpose objective | What public, institutional, or infrastructure capability must the digital infrastructure support? | Digital infrastructure objective manifest |
| Connectivity | Which users, institutions, devices, and assets have reliable, affordable, high-quality access? | Connectivity infrastructure inventory |
| Compute and storage | Which data centers, cloud regions, edge nodes, storage systems, and compute platforms sustain services? | Cloud and data infrastructure register |
| Interoperability | Which systems must exchange data, and are shared standards, schemas, APIs, and registries in place? | Interoperability and exchange register |
| Identity and trust | How do users, institutions, systems, and devices authenticate, authorize, consent, transact, and audit? | Identity and trust register |
| Continuity and dependency | Which critical services depend on concentrated vendors, cloud regions, identity systems, or platforms? | Dependency and continuity review |
| Access and inclusion | Who is excluded by geography, affordability, accessibility, device needs, language, documentation, or digital literacy? | Access and inclusion review |
| Governance and accountability | Are risks, outages, procurement dependencies, public claims, and service obligations reviewable? | Governance action log |
