# Public Evidence Package Template

Required public-facing fields:

- digital infrastructure system name and scope
- public-purpose statement, service obligations, critical users, and responsible institutions
- connectivity coverage, latency, bandwidth, uptime, affordability, accessibility, and service-quality caveats
- cloud, data center, edge, compute, storage, region, backup, and portability dependencies
- interoperability standards, APIs, schemas, data exchange agreements, and integration-test status
- identity, trust, consent, authentication, authorization, auditability, and rights safeguards
- cybersecurity controls, incident response, continuity planning, failover, recovery, and degraded-mode operation
- access and inclusion impacts across geography, income, disability, language, documentation, device access, and assisted-service needs
- vendor dependency, procurement requirements, competition concerns, exit strategies, and portability status
- outage reporting, public communication, review cycle, limitations, and governance action status
