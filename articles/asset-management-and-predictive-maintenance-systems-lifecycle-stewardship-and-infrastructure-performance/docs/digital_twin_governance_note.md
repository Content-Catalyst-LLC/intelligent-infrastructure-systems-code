# Digital Twin Governance Note

A digital twin for asset management should not be treated as a visualization layer alone. It should document:

- physical asset scope
- data sources
- telemetry update frequency
- model version
- state-estimation method
- maintenance history linkage
- failure-mode assumptions
- lifecycle-cost assumptions
- scenario logic
- uncertainty and validation status
- decision-use limits
- governance owner

A twin that appears precise while hiding model assumptions can create false confidence. A useful twin makes evidence, assumptions, and intervention pathways inspectable.
