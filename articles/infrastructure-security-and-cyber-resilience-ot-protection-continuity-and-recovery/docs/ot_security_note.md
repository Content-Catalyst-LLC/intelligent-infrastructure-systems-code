# OT Security Note

Operational technology security differs from ordinary enterprise IT security because infrastructure control environments often involve:

- legacy devices
- proprietary protocols
- long asset lifetimes
- constrained patch windows
- engineering workstations
- vendor-maintained equipment
- safety-critical processes
- deterministic timing
- limited downtime tolerance
- process-integrity requirements

OT cyber resilience should be judged by whether physical processes remain safe, observable, recoverable, and governable under degraded digital conditions.
