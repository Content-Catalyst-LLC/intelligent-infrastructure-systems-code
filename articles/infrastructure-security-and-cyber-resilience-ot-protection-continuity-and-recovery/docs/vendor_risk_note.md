# Vendor and Supply-Chain Risk Note

Infrastructure cybersecurity extends beyond the operator boundary.

Vendor-risk review should document:

- remote support pathways
- privileged access
- managed service providers
- cloud and telecommunications dependencies
- software components and update channels
- contract security clauses
- concentration risk
- incident notification requirements
- fallback procedures
- exit or substitution plans

Procurement and contract management are part of the cybersecurity perimeter.
