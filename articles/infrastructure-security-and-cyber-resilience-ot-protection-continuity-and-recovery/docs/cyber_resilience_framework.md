# Infrastructure Security and Cyber Resilience Framework

| Layer | Question | Evidence artifact |
|---|---|---|
| Governance and risk | Who owns cyber risk, approves exceptions, funds remediation, and accepts residual exposure? | Cyber governance log |
| Asset visibility | Which IT, OT, field, software, identity, vendor, and data-flow assets exist? | Cyber asset register |
| Identity and access | Which users, service accounts, privileged accounts, and vendors can access critical systems? | Access review record |
| Segmentation and protection | How are IT, OT, public, vendor, and safety-relevant zones separated and controlled? | OT zone and conduit map |
| Detection and monitoring | Can abnormal cyber and operational behavior be detected and triaged? | Monitoring coverage and detection rules |
| Response and containment | Can teams contain compromise without unsafe process effects? | Incident playbooks and tabletop records |
| Recovery and continuity | Can essential services continue or recover safely under degraded conditions? | Continuity and recovery log |
| Vendor and supply chain | Which suppliers, software, remote support paths, and cloud dependencies shape exposure? | Vendor-risk register |
| Public evidence | Can resilience posture be explained without exposing sensitive details? | Public evidence package |
