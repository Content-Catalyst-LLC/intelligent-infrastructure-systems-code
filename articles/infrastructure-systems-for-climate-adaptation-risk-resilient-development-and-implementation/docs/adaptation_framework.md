# Climate Adaptation Infrastructure Framework

| Layer | Question | Evidence artifact |
|---|---|---|
| Climate-risk evidence | Which hazards, baselines, scenarios, and uncertainty ranges matter? | Climate scenario manifest |
| Asset and service exposure | Which assets and essential services are exposed? | Infrastructure exposure inventory |
| Vulnerability and equity | Which populations face higher exposure and lower adaptive capacity? | Vulnerability indicators |
| Adaptation options | Which engineered, ecological, operational, standards, or relocation options reduce risk? | Adaptation option portfolio |
| Finance and delivery | Which options are funded, delivered, maintained, and monitored? | Finance and implementation log |
| Maladaptation review | Could an option transfer risk, lock in exposure, or deepen inequity? | Maladaptation checklist |
| Governance and learning | Who owns decisions, revises standards, and updates assumptions? | Governance log |
