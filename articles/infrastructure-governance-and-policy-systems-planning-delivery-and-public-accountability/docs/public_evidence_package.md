# Public Evidence Package Template

Required public-facing fields:

- project or program name
- public-service problem
- affected public
- alternatives considered
- decision rationale
- strategic fit
- estimated capital cost
- life-cycle cost caveat
- maintenance and renewal obligation
- procurement method
- delivery status
- public-value score caveat
- risk and resilience caveat
- consultation summary
- audit and accountability status
- responsible institution
- review history
- sensitive-information caveat
