# Life-Cycle Stewardship Note

Infrastructure governance should distinguish a capital event from a continuing service obligation.

Stewardship review should document:

- asset condition
- maintenance plan
- funded annual maintenance
- required annual maintenance
- maintenance backlog
- service-level indicators
- operating capacity
- renewal schedule
- climate or resilience vulnerability
- responsible institution

A completed project can still be a governance failure if it cannot be operated, maintained, renewed, or adapted responsibly.
