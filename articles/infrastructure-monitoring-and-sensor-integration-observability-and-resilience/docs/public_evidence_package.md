# Public Evidence Package Template

Required public-facing fields:

- monitoring system name and scope
- monitored infrastructure domains, assets, service zones, and environmental contexts
- monitoring purpose, decision uses, valid-use limits, and prohibited uses
- sensor types, placement rationale, sampling interval, units, calibration status, and sensor-health status
- telemetry latency, missingness, invalid readings, packet loss, freshness, and data-quality caveats
- coverage, blind spots, high-risk zones, vulnerable communities, and unmonitored conditions
- observability, actionability, validation, and monitoring-enabled resilience indicators
- alert thresholds, response pathways, inspection workflows, maintenance workflows, and public communication rules
- cybersecurity, access control, firmware governance, incident response, backup, and continuity safeguards
- responsible owners, operators, vendors, reviewers, regulators, and governance authority
- reporting schedule, review cycle, limitations, and uncertainty statements

Public-facing evidence should distinguish raw readings, calibrated readings, quality-controlled records, analytical outputs, operational decisions, and public claims.
