# Edge Sensor Validation Model Card

## Intended use

- demonstrate edge validation for infrastructure monitoring records
- detect missing metadata, high latency, low battery, invalid schema, invalid units, sensor-health concerns, and calibration problems
- compare embedded C, MicroPython, and HDL validation patterns

## Not intended for

- production stream processing
- certified operations
- public safety automation
- cybersecurity certification
- replacing platform governance, calibration programs, or field validation
