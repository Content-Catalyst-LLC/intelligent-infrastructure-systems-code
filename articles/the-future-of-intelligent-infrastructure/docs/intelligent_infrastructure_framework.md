# Intelligent Infrastructure Public Systems Framework

| Layer | Question | Evidence artifact |
|---|---|---|
| Physical assets and services | What critical assets, services, owners, and dependencies exist? | Asset and service register |
| Observability | Which assets, conditions, failure modes, and communities are visible? | Observability registry and coverage audit |
| Interoperability | Can systems exchange data with shared identifiers and governed schemas? | Interoperability map |
| AI and analytics | Which models support decisions and how are they governed? | AI and analytics registry |
| Cyber resilience | Can digital and operational systems be protected, isolated, and recovered? | Cyber-resilience control matrix |
| Resilience scenarios | Which climate, demand, outage, cyber, and cascading-failure futures have been tested? | Resilience scenario manifest |
| Public value | Are reliability, equity, sustainability, resilience, security, and accountability measured? | Infrastructure intelligence KPI table |
| Decision action | Do insights connect to work orders, budgets, emergency response, planning, or public action? | Decision and intervention log |
| Governance | Who owns review, public evidence, model updates, and accountability? | Governance review log |
