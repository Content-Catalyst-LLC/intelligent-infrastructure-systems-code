# Climate Monitoring Infrastructure Framework

| Layer | Question | Evidence artifact |
|---|---|---|
| Variable definition | Which climate variables are essential for the intended scientific and decision use? | Essential Climate Variable map |
| Observing network | Which stations, satellites, buoys, towers, gauges, and platforms produce the record? | Station and platform inventory |
| Metadata and calibration | Can measurement changes be distinguished from climate signals? | Instrument metadata and calibration log |
| Archive and provenance | Can records be traced, versioned, and recovered over decades? | Archive manifest |
| Baseline and anomaly analysis | How are reference periods, anomalies, trends, and missingness handled? | Baseline and anomaly workflow |
| Services and decision support | How does climate evidence support planning, risk, adaptation, and public reporting? | Climate-service evidence package |
| Governance and continuity | Who maintains standards, data access, calibration, and long-term stewardship? | Governance log and continuity plan |
