# Metadata Dictionary

| Field | Meaning |
|---|---|
| station_id | Stable identifier for a station or platform |
| platform_type | Surface station, buoy, tower, satellite product, gauge, etc. |
| domain | Atmosphere, ocean, land, cryosphere, carbon, hydrology |
| variable | Climate variable observed |
| instrument_type | Instrument or sensor class |
| calibration_status | Current, expired, review_required |
| metadata_status | Complete, partial, missing, review_required |
| record_start | First date in expected climate record |
| record_end | Last date in expected climate record |
| quality_flag | Status flag for observation-level quality |
| archive_version | Version identifier for dataset or archive product |
