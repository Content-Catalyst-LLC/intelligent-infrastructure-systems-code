# Public Evidence Package Template

Required public-facing fields:

- climate monitoring system name and scope
- variables and domains covered
- observing platforms used
- baseline period and anomaly method
- station and platform metadata status
- calibration and quality-control status
- record completeness and known gaps
- archive version and provenance
- uncertainty and valid-use caveats
- governance owner
- review history

Public-facing evidence should distinguish raw observations, quality-controlled records, homogenized records, reanalysis products, and public indicators.
