# Transportation Mobility Model Card

## Intended use

- compute illustrative reliability, mobility quality, accessibility gap, safety risk, coordination, and recovery-lag indicators
- flag network elements requiring governance, operations, maintenance, or planning review
- support reproducible intelligent transportation examples

## Not intended for

- certified transport operations
- public-safety automation
- signal control without expert review
- accessibility compliance determination
- cybersecurity certification
- replacement for transport planning judgment

## Required caveats

Sample data and thresholds are illustrative. Real deployment requires validated transport data, field review, accessibility analysis, cybersecurity review, public authority, and governance approval.
