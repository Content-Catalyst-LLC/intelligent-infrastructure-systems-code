# Public Evidence Package Template

Required public-facing fields:

- transportation system name and scope
- public mobility goals and decision uses
- modes, routes, corridors, assets, and service zones covered
- data sources, latency, missingness, and quality caveats
- reliability, accessibility, safety, emissions, and recovery metrics
- freight, curb, transit, walking, cycling, and emergency-access considerations
- cybersecurity, privacy, access, and fallback safeguards
- responsible agencies and operators
- public reporting schedule
- governance authority and review cycle
- limitations and non-operational caveats

Public-facing evidence should distinguish raw telemetry, quality-controlled records, indicators, model outputs, operational decisions, and public claims.
