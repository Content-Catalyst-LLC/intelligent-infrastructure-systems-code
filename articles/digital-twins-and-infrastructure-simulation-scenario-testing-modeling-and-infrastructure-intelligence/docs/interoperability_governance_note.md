# Interoperability Governance Note

Digital twins become durable infrastructure only when they can exchange meaning across systems and institutions.

Important interoperability concerns:

- stable asset identifiers
- shared units and time standards
- schema governance
- GIS/BIM/asset-register linkage
- telemetry metadata
- API documentation
- model versioning
- access controls
- cyber-physical risk review
- public evidence documentation

Interoperability is therefore not just an engineering problem. It is an institutional governance requirement.
