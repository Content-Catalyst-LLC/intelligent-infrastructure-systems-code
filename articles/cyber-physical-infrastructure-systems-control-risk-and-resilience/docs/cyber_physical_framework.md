# Cyber-Physical Infrastructure Framework

| Layer | Question | Evidence artifact |
|---|---|---|
| Service and control objective | What physical service is being preserved, what control purpose is valid, and who has authority? | Cyber-physical objective manifest |
| Physical assets | Which assets, processes, service zones, and physical constraints are involved? | Cyber-physical asset inventory |
| Sensing and telemetry | How is physical state measured, transmitted, calibrated, validated, and quality-flagged? | Telemetry and command records |
| Computation and control | How are readings converted into state estimates, rules, setpoints, commands, or operator decisions? | Control-loop register |
| Actuation and intervention | How do digital decisions become physical actions? | Command and intervention log |
| Dependency and exposure | Which cyber services, vendors, identity systems, cloud services, networks, and firmware dependencies support physical functions? | Dependency and exposure map |
| Assurance and fallback | Can the system degrade safely, isolate, recover, and operate manually when needed? | Assurance and fallback review |
| Governance and accountability | Are cyber-physical findings connected to engineering review, cybersecurity response, operations, procurement, training, or public reporting? | Governance action log |
