# Public Evidence Package Template

Required public-facing fields:

- cyber-physical system name and scope
- physical service, assets, service zones, and operating constraints
- control purpose, valid-use limits, prohibited uses, automation level, and human authority
- sensors, telemetry, control logic, actuators, platforms, vendors, and dependency pathways
- signal quality, telemetry reliability, validation status, safety boundaries, and uncertainty caveats
- cyber-physical dependency, exposure, fallback capability, manual override, and recovery readiness
- incident response, recovery testing, operator training, after-action review, and governance closure
- cybersecurity safeguards, segmentation, access controls, firmware governance, logging, and vendor oversight
- responsible owners, operators, engineers, vendors, regulators, and public reporting authority
- public limitations, review cycle, reporting schedule, and non-operational caveats

Public-facing evidence should distinguish raw telemetry, state estimation, control recommendations, authorized commands, physical interventions, and public claims.
