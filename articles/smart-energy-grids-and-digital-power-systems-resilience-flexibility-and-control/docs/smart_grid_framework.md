# Smart Grid Infrastructure Framework

| Layer | Question | Evidence artifact |
|---|---|---|
| Grid-service objective | What service, reliability, flexibility, resilience, and public-accountability goals should the system support? | Smart grid objective manifest |
| Physical grid assets | Which generation, transmission, distribution, storage, DER, EV, meter, microgrid, and control-system assets are included? | Grid asset inventory |
| Sensing and telemetry | Are voltage, frequency, current, flow, loading, outage, storage, DER, and device-health records captured? | Grid telemetry records |
| Distributed coordination | Are DERs, storage, EV charging, flexible loads, aggregators, microgrids, and dispatch permissions tracked? | Distributed resource coordination register |
| Reliability and resilience | Are outages, restoration, service continuity, backup capability, response capacity, and exposure recorded? | Grid reliability and resilience review |
| Cyber-physical integrity | Are SCADA, AMI, DERMS, OMS, field devices, remote access, firmware, telemetry, and fallback procedures protected? | Cyber-physical grid review |
| Governance and interoperability | Are standards, procurement, regulatory, customer, cybersecurity, and institutional-review actions documented? | Governance and interoperability log |
