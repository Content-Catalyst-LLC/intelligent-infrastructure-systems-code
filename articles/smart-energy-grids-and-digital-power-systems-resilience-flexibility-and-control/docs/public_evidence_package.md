# Public Evidence Package Template

Required public-facing fields:

- smart grid system name and scope
- grid-service purpose and decision uses
- generation, transmission, distribution, storage, DER, EV, flexible load, microgrid, and control-system assets covered
- telemetry sources, latency, missingness, time synchronization, calibration, and quality caveats
- observability, voltage adequacy, flexibility adequacy, balancing pressure, service continuity, cyber-physical risk, and resilience metrics
- outage response, restoration, DER coordination, field response, public communication, and capital-planning pathways
- cybersecurity, SCADA protection, telemetry continuity, device governance, remote access controls, and fallback safeguards
- responsible utilities, system operators, regulators, aggregators, vendors, operators, and governance authority
- reporting schedule and review cycle
- limitations and non-operational caveats

Public-facing evidence should distinguish raw telemetry, quality-controlled records, model outputs, operational decisions, reliability claims, regulatory claims, and public communication.
