# Public Evidence Package Template

Required public-facing fields:

- renewable infrastructure system name and scope
- public/service purpose and decision uses
- renewable asset classes, grid nodes, storage systems, flexibility resources, and service zones covered
- forecast sources, telemetry sources, latency, missingness, resource conditions, and quality caveats
- curtailment, usable renewable energy, grid constraint, storage readiness, flexibility adequacy, and resilience metrics
- interconnection queue status, hosting capacity, reinforcement needs, and permitting status
- cybersecurity, inverter/device visibility, telemetry continuity, and fallback safeguards
- responsible agencies, operators, owners, vendors, regulators, and governance authority
- reporting schedule and review cycle
- limitations and non-operational caveats

Public-facing evidence should distinguish raw telemetry, quality-controlled records, indicators, model outputs, planning decisions, operational decisions, and public claims.
