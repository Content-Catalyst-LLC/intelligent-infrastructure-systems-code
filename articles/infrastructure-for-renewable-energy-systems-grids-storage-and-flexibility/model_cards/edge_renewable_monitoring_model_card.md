# Edge Renewable Monitoring Model Card

## Intended use

- demonstrate edge validation for renewable telemetry
- detect voltage, inverter thermal, forecast error, generation range, low power, stale telemetry, and fallback problems
- compare embedded, MicroPython, and HDL validation patterns

## Not intended for

- certified renewable plant monitoring
- protection-system control
- grid operations automation
- market settlement
- replacing cybersecurity or operator review
