# Public Evidence Package Template

Required public-facing fields:

- intelligent water system name and scope
- water-service purpose and decision uses
- asset classes, service zones, hydraulic zones, treatment facilities, wastewater systems, stormwater systems, and sensors covered
- telemetry sources, laboratory sources, latency, missingness, calibration, sampling coverage, and quality caveats
- water-quality compliance, pressure adequacy, leakage/non-revenue water, service continuity, observability, overflow risk, and resilience metrics
- treatment, maintenance, field response, public-health, public communication, and capital-planning response pathways
- cybersecurity, SCADA protection, telemetry continuity, device governance, and fallback safeguards
- responsible utilities, public-health agencies, regulators, vendors, operators, and governance authority
- reporting schedule and review cycle
- limitations and non-operational caveats

Public-facing evidence should distinguish raw telemetry, calibrated readings, laboratory evidence, quality-controlled records, model outputs, operational decisions, public-health actions, and public claims.
