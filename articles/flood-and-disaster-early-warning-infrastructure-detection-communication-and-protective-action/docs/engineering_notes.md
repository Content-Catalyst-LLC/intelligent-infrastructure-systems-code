# Engineering Notes

## Design priorities

Early warning infrastructure should be engineered around the warning-action chain:

1. Detect hazard conditions.
2. Estimate likely impacts.
3. Decide whether to warn.
4. Issue clear and accessible warnings.
5. Disseminate through redundant channels.
6. Enable protective action.
7. Observe actual outcomes.
8. Learn and improve.

## Common failure modes

- observation telemetry outage
- uncalibrated gauges
- model output not translated into local impact
- warning thresholds unclear
- decision authority delayed
- telecom channel unavailable
- alert message inaccessible
- evacuation route already blocked
- shelter capacity insufficient
- community trust too low for action
- after-action review not performed
