# Public Evidence Package Template

Required public-facing fields:

- warning system name and scope
- hazards covered
- exposed communities and critical services
- observation network status
- forecast and threshold caveats
- warning channels used
- accessibility and inclusion caveats
- preparedness and protective action protocols
- known gaps and residual risk
- governance owner
- after-action review process
- review history

Public-facing evidence should distinguish alerts that can be issued from warnings that can be received, understood, trusted, and acted upon.
