# Edge Threshold Model Card

## Intended use

- demonstrate local threshold logic for rainfall, river stage, and soil saturation
- support engineering discussion of edge telemetry and local watch triggers
- compare embedded, MicroPython, and HDL threshold logic

## Not intended for

- live flood warning issuance
- replacing hydrological models
- bypassing emergency-management authority

## Required caveats

- thresholds are illustrative
- field deployment requires calibration, redundancy, maintenance, power resilience, telemetry validation, and governance review
