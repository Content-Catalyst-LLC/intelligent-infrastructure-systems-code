# Metadata Dictionary

| Field | Meaning |
|---|---|
| site_id | Stable identifier for a monitoring site |
| monitoring_zone_id | Spatial zone used for coverage and exposure review |
| domain | Air, water, land, climate, biodiversity, pollution, or ecosystem domain |
| variable | Environmental variable observed |
| unit | Measurement unit |
| method | Sensor, laboratory, field, remote-sensing, or model method |
| quality_flag | Observation-level quality status |
| calibration_status | Current, expired, review_required |
| telemetry_status | Current, partial, offline, review_required |
| threshold_value | Domain-specific threshold or management trigger |
| exposure_score | Relative exposure score for monitored zone |
| vulnerability_score | Relative vulnerability score for monitored zone |
| governance_response_score | Strength of response pathway |
