# Systems-Engineering Lifecycle

| Lifecycle stage | Climate-adaptation question | Evidence artifact |
|---|---|---|
| Requirements | Which service must continue, for whom, under which hazard and time horizon? | Requirements register, service-continuity target |
| Architecture | Which assets, ecological buffers, data systems, and institutions must coordinate? | Reference architecture, dependency graph |
| Design | Which intervention set reduces risk without transferring harm? | Adaptation option register, trade-off analysis |
| Verification | Was the intervention built or configured as specified? | Inspection record, commissioning report, test evidence |
| Validation | Does the intervention protect the intended service and population under plausible stress? | Scenario exercise, outage drill, public evidence package |
| Operations | Can the system be maintained, monitored, and updated? | Maintenance plan, telemetry report, governance log |
| Revision | What changed in climate assumptions, exposure, standards, finance, or public need? | Revision log, trigger thresholds, standard update record |
