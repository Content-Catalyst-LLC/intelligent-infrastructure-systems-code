# Failure Modes and Effects Review

| Failure mode | Example | Review question |
|---|---|---|
| Design-basis failure | Drainage sized for obsolete rainfall assumptions | Are future climate baselines incorporated? |
| Service-continuity failure | Cooling center loses power during heat emergency | Are dependency chains protected? |
| Transfer of risk | Flood wall redirects water toward lower-income neighborhood | Has maladaptation been screened? |
| Maintenance failure | Green infrastructure loses storage capacity over time | Is lifecycle funding assigned? |
| Data failure | Asset dashboard lacks outage and vulnerability indicators | Are observability requirements defined? |
| Finance failure | Plan exists but capital and operating funds do not | Is implementation readiness realistic? |
| Governance failure | Multiple agencies own pieces but no one owns revision | Is accountability assigned? |
