# Adaptation Readiness Model Card

## Intended use

- triage adaptation infrastructure projects
- identify scenario, dependency, service, finance, maintenance, equity, observability, governance, and maladaptation review needs
- support transparent public evidence packages
- create reproducible sample workflows for article companion code

## Not intended for

- replacing engineering design
- replacing hydrologic, thermal, coastal, wildfire, geotechnical, or power-system modeling
- replacing public participation or community decision-making
- certifying adaptation success
- producing final project rankings without local evidence

## Known limitations

The scoring model uses illustrative normalized values. A real implementation should document how each score is derived, who validates it, what uncertainty range applies, and how public priorities affect weighting.
