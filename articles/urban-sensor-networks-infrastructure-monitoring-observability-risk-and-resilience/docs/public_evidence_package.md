# Public Evidence Package Template

Required public-facing fields:

- sensor-network name and scope
- public purpose and operational use cases
- infrastructure domains and variables covered
- sensor placement and coverage caveats
- device metadata and calibration status
- quality flags and missingness notes
- latency and uptime limits
- cybersecurity, privacy, access, and retention safeguards
- indicators, thresholds, and valid-use limits
- responsible agency or operator
- response workflow and review cycle
- public reporting schedule

Public-facing evidence should distinguish raw telemetry, quality-controlled records, alerts, model outputs, operational decisions, and public claims.
