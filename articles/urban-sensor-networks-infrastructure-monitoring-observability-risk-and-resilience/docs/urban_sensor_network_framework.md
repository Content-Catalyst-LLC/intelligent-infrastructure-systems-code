# Urban Sensor Network Infrastructure Framework

| Layer | Question | Evidence artifact |
|---|---|---|
| Monitoring objective | What public, operational, environmental, or infrastructure question is the sensing system meant to answer? | Urban sensing objective manifest |
| Sensing and device layer | Which devices, locations, variables, and assets generate observations? | Sensor inventory and asset linkage table |
| Telemetry and connectivity | How do readings move from device to platform under normal and disrupted conditions? | Telemetry log and communications architecture |
| Metadata and quality | Can sensor readings be trusted, interpreted, and compared over time? | Calibration and device-health log |
| Data integration | Can sensor data be linked to infrastructure assets, service zones, incidents, and maintenance records? | SQL schema, data catalog, API notes |
| Analytics and interpretation | How are anomalies, thresholds, alerts, and urban observability indicators produced? | Indicator catalog and model card |
| Security and rights | How are privacy, cybersecurity, access, retention, and public legitimacy protected? | Governance policy and access review |
| Response and stewardship | Who acts when monitoring detects risk or service degradation? | Governance and response log |
